# MMT Fees Manager — Phase 1

Mobile-first coaching fees management prototype based on the supplied UI reference screenshots.

## Included in Phase 1
- Dashboard with monthly overview cards
- Students list + search
- Add Student form
- Monthly fee generation
- Payment records: Pending / Paid
- Mark Paid / Revert
- WhatsApp reminder / Call shortcuts
- Receipt preview
- Reports summary + pending fees
- Drawer navigation
- Bottom navigation
- localStorage persistence
- Vercel-ready static structure

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Vercel
Import the folder/repository into Vercel. No build command is required for this static Phase 1 version.

## Next phase
Firebase Auth + Firestore + Storage, edit/delete flows, real month selection, production receipt/PDF, secure rules, backups, then Capacitor/Android.
